# Mobile App Document Upload Flow - Fixed ✅

## Problem
Documents from mobile app were being uploaded to a temporary `los-pending` folder instead of the final application folder (`los-{id}`), causing them to not appear in the Document Explorer or web dashboard.

## Root Cause
- Mobile app didn't have a LOS ID at the time of document upload (application not yet created)
- Documents were uploaded with hardcoded `losId: 'pending'`
- Backend didn't move documents from temporary storage to final location

## Solution Implemented

### 1. Mobile App Changes (`DocumentUploadScreen.jsx`)
**Before:**
```javascript
losId: 'pending', // Will be updated when LOS ID is assigned
```

**After:**
```javascript
losId: `temp-${customerCnic}`, // Temporary folder by CNIC, will be moved to los-{id} when application is created
```

### 2. Backend Changes (`application.service.v2.js`)

#### Updated `storeDocuments()` function:
- Now accepts `cnic` parameter
- Looks for documents in `temp-{cnic}` folder
- Copies all documents from `temp-{cnic}` to `los-{id}` folder
- Cleans up temporary folder after successful copy

#### Flow:
1. Mobile app uploads CNIC and Salary Slip to: `/ilos_loan_application_documents/cashplus/temp-3840393463961/`
2. User submits application from mobile
3. Backend creates application (LOS-79)
4. Backend's `storeDocuments()` finds `temp-3840393463961` folder
5. Backend copies all files to: `/ilos_loan_application_documents/cashplus/los-79/`
6. Backend deletes `temp-3840393463961` folder
7. Backend generates Application PDF in same folder

## Final Result

Each application folder now contains:
```
/ilos_loan_application_documents/cashplus/los-79/
├── cnic_3840393463961.jpg          ✅ From mobile OCR
├── salarySlip_3840393463961.jpg    ✅ From mobile OCR
└── 79-Application.pdf               ✅ Generated by backend
```

## Benefits
1. ✅ No more manual document moving
2. ✅ Documents automatically appear in Document Explorer
3. ✅ PB officers can see all documents when reviewing mobile submissions
4. ✅ Clean separation: temp folder for in-progress uploads, final folder for submitted applications
5. ✅ Automatic cleanup of temporary files
